# NutriPlan Pro
A modern mobile application for creating personalized nutrition and meal plans, powered by Flutter, Firebase, and Spoonacular API.

## Project Overview
NutriPlan Pro is a comprehensive mobile platform that helps users create and manage personalized nutrition plans based on their individual needs and preferences. The app calculates personalized caloric requirements and macronutrient distributions based on user data. Key features include:

- User authentication and profile management
- Customizable meal plans
- Favorite meals and plan saving
- Social sharing capabilities
- Smart shopping list generation
- Collaborative shopping lists with friends
- Enhanced UI/UX experience

## Technologies Used
This project is built with:
* Flutter 3.7.10
* Dart 2.19.6
* Firebase for backend services
* Spoonacular API for nutrition data

## Getting Started
1. Clone this repository
2. Set up Firebase project and add your configuration
3. Get a Spoonacular API key from https://spoonacular.com/food-api
4. Add your API keys to the configuration
5. Run `flutter pub get` to install dependencies
6. Launch the app with `flutter run`
